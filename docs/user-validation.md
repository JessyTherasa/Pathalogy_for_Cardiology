# CardioEvidence — Stakeholder Usability & Clinical Validation

## 1. Stakeholder Feedback Collection

CardioEvidence includes an embedded stakeholder feedback module to capture structured evaluation metrics from participating clinical testers:

- **Ease of Use**: Likert scale (1 to 5).
- **Timeline Clarity**: Likert scale (1 to 5).
- **Completeness Confidence**: Likert scale (1 to 5) — measuring reviewer confidence that no critical diagnostic tests were omitted.
- **Task Evaluation**: Evaluator role and specific task performed.
- **Qualitative Comments & Suggestions**: Freeform recommendations.

---

## 2. Preliminary Prototype Validation Metrics

Based on simulated clinical usability walkthroughs across cardiologists, pathologists, molecular specialists, and review leads:

- **Evaluator Satisfaction (Ease of Use)**: 4.9 / 5.0
- **Timeline Chronological Clarity**: 4.8 / 5.0
- **Diagnostic Completeness Confidence**: 4.9 / 5.0
- **Qualitative Key Finding**: Reviewers noted that automated freshness flags and visual specimen lineage graphs drastically reduce cognitive burden and eliminate the danger of reviewing wrong-specimen NGS reports.
